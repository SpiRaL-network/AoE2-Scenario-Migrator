# Changelog

## 0.1.0 - 2026-08-15

- First professional preview.
- AoK 1.18–1.21, AoC 1.22 and HD 1.23/1.24/1.26 readers.
- Dynamic latest-supported DE output; no hard-coded DE target revision.
- Rule-based safe repair engine and opt-in aggressive duplicate-ID repair.
- Atomic writes, recoverable overwrite, SHA-256 provenance and JSON/HTML reports.
- Full post-write reopen validation for map, terrain, units, triggers and messages.
- Batch CLI and native Windows GUI.
